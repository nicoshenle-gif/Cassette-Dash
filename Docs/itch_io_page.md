## 详细描述（Description，可直接粘贴）

### 简体中文

**Cassette Dash!** 是一款发生在磁带内部的 2.5D 跑酷小游戏。

你醒来时发现自己在一盘老式磁带的壳子里。唯一出去的路，是穿过整个走带机构，登上那列从磁带中驶出的火车。

**玩法特色**
- **磁带就是跑道**：左右两个齿轮之间的磁带带子可以跑、可以踩。
- **长按 E / Q 吐带**：长按会转动齿轮放出磁带——左侧带子会凹陷成吊床缓冲落地；右侧带子则能借力把你弹上齿轮。
- **机关与躲避**：升降刺、磁头压板、上方投放器，以及两侧会朝你瞄准的弩车——注意蓄力时的橙色警示线，锁定后走出那条线就能躲开。
- **完整通关流程**：跨越磁带 → 爬上梯子 → 跳上屋顶列车，结算通关用时与剩余血量。
- **多语言界面**：简体中文 / English / 日本語 / 한국어 / Español，开始界面可随时切换。

**操作**
| 按键 | 功能 |
|---|---|
| `A` / `D` | 左右移动 |
| `←` / `→` | 里外（景深）移动 |
| `Space` | 跳跃 |
| `Ctrl` | 蹲下 |
| 长按 `E` | 吐左侧磁带（凹陷成吊床） |
| 长按 `Q` | 吐右侧磁带（弹上右齿轮） |
| `F` | 交互 / 上梯 / 上车 |
| `R` | 重生 |
| `1`–`5` | 开始界面切换语言 |

### English

**Cassette Dash!** is a short 2.5D parkour game that takes place *inside* a cassette tape.

You wake up trapped in the shell of an old cassette. The only way out is to cross the whole tape transport mechanism and board the train that leaves the tape.

**Features**
- **The tape is the track** — run and land on the tape spans between the two reels.
- **Hold E / Q to feed tape** — the left span sags into a soft hammock, while the right one can fling you up onto the reel.
- **Hazards** — telescoping needle spikes, the slamming magnetic head, overhead droppers, and crossbow turrets on both walls. Watch their orange aim line: once it locks, step off it and the bolt flies past you.
- **A complete run** — cross the tape, climb the ladder, hop on the roof train, and get your clear time and remaining health on the results screen.
- **Localised UI** — 简体中文 / English / 日本語 / 한국어 / Español, switchable from the title screen.

**Controls**
| Key | Action |
|---|---|
| `A` / `D` | Move left / right |
| `←` / `→` | Depth (in / out) |
| `Space` | Jump |
| `Ctrl` | Crouch |
| Hold `E` | Feed the left tape (sags into a hammock) |
| Hold `Q` | Feed the right tape (flings you onto the reel) |
| `F` | Interact / climb ladder / board train |
| `R` | Respawn |
| `1`–`5` | Change language on the title screen |

## 发布方式（二选一）

### A. 网页上传（最简单）
1. 把 `Builds/Windows/` 整个文件夹压缩成 zip（确保解压后第一层就是 `CassetteDash.exe` 与 `CassetteDash_Data/`）。
2. itch 项目页 → **Uploads** → 上传 zip → 勾选 **This file will be played in the browser** 只对 WebGL 有意义，Windows 版保持默认（下载型）。
3. 设置 **Executable / 或 This file is a Windows build** → 选择 `CassetteDash.exe`。

### B. butler 命令行（推荐，可增量上传）
```powershell
# 安装 butler（任选其一）
winget install --id itch.io.butler
# 或从 https://itch.io/docs/butler/ 下载后解压到 PATH

butler login
butler push "Builds/Windows" nico0622/cassette-dash:windows --userversion 1.0
```
推送完成后在项目页把该 build 标记为默认下载即可。

## 常见坑

- **zip 层级**：不要出现 `Builds/Windows/CassetteDash.exe` 这种多套一层的结构，解压后必须直接是 exe。
- **杀毒误报**：Unity 未签名 exe 偶尔会被误报，可在页面说明并建议玩家添加白名单。
- **WebGL 版**：本次没有构建（需要先在 Unity Hub 给 6000.4.3f1 安装 WebGL Build Support 模块）；当前 395 MB 的美术资源会让 WebGL 包偏大，建议先做贴图压缩再考虑。
- **不要上传**：`Library/`、`Temp/`、`Builds/` 源码工程目录本身——只上传构建产物。
